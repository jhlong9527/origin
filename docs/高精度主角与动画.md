# 高精度主角与动画

当前默认主角使用用户提供的 OBJ 外观，在 Blender 中重新建立骨骼、权重和动画。
原始模型是把身体、剑盾和披风焊接在一起的单一网格；新资源分离了剑盾，保留原 UV 和原色、粗糙度、金属度、法线贴图。左臂被盾牌粘连遮挡的部分以另一侧完整手臂为基础补建，并封闭了武器接触处的切口。

## 资源与回退

- 游戏资源：`assets/characters/wayfarer_rigged.glb`。
- Blender 工程：`assets/characters/source_high_detail/wayfarer_rigged.blend`，贴图已打包。
- 生成脚本：`tools/build_rigged_hero.py`。
- 高精度运行时：`scripts/rigged_hero_visual.gd`。
- 原主角：`assets/characters/wayfarer.blend`、`assets/characters/wayfarer.glb`，原样保留。
- 静态参考模型：`assets/characters/wayfarer_reference.glb`；原始 OBJ/PBR 在 `_incoming_model/`。

默认 `project.godot` 的 `gameplay/hero_model="high_detail"`。
改为 `"legacy"` 可恢复原角色；双击工程根目录的 `Start-Legacy-Hero.cmd` 可以临时用旧角色启动，无须更改工程设置。等效命令：

```powershell
& 'D:\godot\Godot_v4.7.2-stable_win64.exe' --path 'D:\godot\warden\-666' -- --legacy-hero
```

Boss 继续使用原资源与动作。主角战斗状态、伤害、碰撞胶囊、按键与技能释放时刻由原 `combat.gd` 管理，视觉脚本采样导出的骨骼动画。

## 动作

19 根骨骼，包括头、躯干、四肢、披风、剑盾；19 组动作包含待机、移动、三段剑击、剑技能、防御、弹反、翻滚、受击、硬直、死亡、喝药、换武器、弓待机/移动、站立/移动搭箭、后空翻三连射。

弓模式隐藏源模型剑盾，左手握弓、右手拉弦；箭筒跟随躯干，弓弦与搭在弦上的箭跟随双手。普通射击在 0.72 秒释放，移动搭箭继续播放腿部步态，翻滚会按原规则中断尚未射出的箭。

Q 后空翻从 0.12 秒开始，0.70 秒落地，随后在 0.92 / 1.14 / 1.36 秒射箭。水平后撤约 1 米，仍由原生胶囊处理墙体碰撞。动画在变形后的身体最低点之上叠加最高 0.50 米的腾空高度，避免贴地校正抵消跳跃。旧角色也修复了同类后空翻穿地问题。

## 重新生成与检查

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python 'D:\godot\warden\-666\tools\build_rigged_hero.py'
& 'D:\godot\Godot_v4.7.2-stable_win64_console.exe' --headless --editor --path 'D:\godot\warden\-666' --import --quit
& 'D:\godot\Godot_v4.7.2-stable_win64_console.exe' --path 'D:\godot\warden\-666' --script res://tests/rigged_hero_review.gd
```

`rigged_hero_review.gd` 捕获关键动作，并用实际蒙皮后的顶点检查后空翻全过程的离地高度。
`bow_combat_checks.gd` 检查换武器、搭箭、打断、弹道、命中留存、技能落地顺序与碰撞；`combat_checks.gd` 和 `integration_checks.gd` 覆盖原剑盾战斗与键鼠输入。
运行战斗测试需附加 `-- --combat-test`；加上 `--legacy-hero` 可验证旧模型回退。

此版本使用程序化关键帧和蒙皮，没有布料模拟或面部表情动画。原始一体网格保留了扫描造型，其衣服接触区域仍不等同于人工重新拓扑的独立衣物。
