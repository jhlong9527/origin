# 荆棘誓约 / Briar Warden

本地 Godot 4.7.2 + Blender 5.2 制作的 PC 俯视剑盾 Boss 战原型。
正交 3D 摄影机、卡通护甲与深色描边、夕阳中的森林废墟庭院。美术参考给定图片的
俯视构图和轮廓处理，采用原创风格化 3D 素材。

- 护甲改用柔和的金属高光，披风保持粗糙织物表面。原有护甲配色、描边、受击闪色、

- 修复上轮遗留的战斗测试缩进与砸地翻滚采样时机，以及接近平行方向转身时的 slerp 警告。

## V2 更新

- 骑士与 Boss 更新为约 3.3 万 / 3.4 万三角形模型，增加曲面甲片、头盔通气槽、
  指节、剑盾浮雕及厚度明确的褶皱披风；按关节合并装饰表面以降低绘制调用。
- 低角度夕阳、暖色直射光、冷色阴影和空气尘埃，配合更丰富的枝叶与废墟细节。
- 玩家与 Boss 动作时长缩至原来的 82%，位移速度对应调整，保留动作承诺和弹反窗口。
- 普通横扫不显示地面预警；突刺使用沿攻击路径的方向性区域及金色弹反闪光；
  砸地使用真实落点、7 米半径预警和从中心向外扩散的冲击波。
- Q 保留突进斩击，并发射沿释放方向前进的剑气：13 米/秒，最多 9 米，
  独立伤害 45；近身斩击伤害 100 可同时命中一次。剑气经扫掠碰撞检测后被墙体阻挡。
- 特效直接读取战斗模拟中的预警、弹道和波前位置；暂停冻结，重试清理。

## 启动

- 双击 `Start-Game.cmd`，调用上级目录现有 Godot。
- `build/BriarWarden.exe` 与同目录 `BriarWarden.pck` 配套，可直接双击启动。
- 编辑工程：使用 Godot 打开 `project.godot`，按 F5 运行。
- 运行不依赖网络，也不需要 Blender；Blender 用于修改和重新生成角色模型。

## 键鼠操作

| 输入 | 动作 |
| --- | --- |
| WASD | 移动，防御时慢步移动 |
| 鼠标移动 | 角色朝向鼠标在地面上的位置；移动与举盾保持鼠标朝向 |
| 鼠标左键 | 朝鼠标方向攻击；第一、二击过程中再次点击可缓存后续连段，每击开始时重新取鼠标朝向 |
| 按住鼠标右键 | 举盾防御 |

| Shift | 朝移动方向翻滚；无移动输入时朝鼠标方向翻滚，翻滚途中方向固定 |
| Q | 霜誓斩，突进斩击并发射前冲剑气，8 秒冷却 |

Y 技能、X 治疗、右摇杆按下锁定、Start 暂停。此次实体输入验证针对键鼠，
手柄映射未经实机验证。

## 战斗

- 玩家 130 生命、100 精力；Boss 1100 生命。
- 三段攻击分别为正向横斩、反向横斩、过顶劈斩。包含蓄力、加速出刃、
  收势和恢复，消耗 17 / 19 / 25 精力，基础伤害 30 / 38 / 55。
- 已开始的攻击、喝药和盾反需要完成动作，不能随时用翻滚取消。
- 防御仅覆盖面向前方，普通攻击保留少量伤害，并消耗精力；精力不足会破防。
- 翻滚耗费 26 精力，总时长约 0.525 秒，无敌区间约 0.074 至 0.353 秒。
- 盾反有效区间为动作开始后 0.08 至 0.25 秒。Boss 金色十字闪光和发光剑刃
  标记可弹反的突刺，成功使 Boss 僵直约 2.21 秒，并提供一次增伤反击。
- Boss 拥有横扫、蓄力砸地冲击波、金色突刺。半血进入第二阶段，加快节奏，
  横扫追加反向追击。横扫和砸地不能弹反。
- 死亡与胜利均可重新挑战，生命、精力、药瓶、冷却和 Boss 状态完整重置。

## 碰撞与动作

世界使用 Godot 原生 CharacterBody3D 胶囊、StaticBody3D 地面和障碍，
按 60 Hz 物理步更新。翻滚保留地面胶囊，翻滚动画只转动身体模型。
角色与 Boss 相互阻挡，近战还检测静态遮挡，无法隔墙伤害。
地面石板、草叶不额外增加绊脚碰撞；四处废墟实体基座和场地边界有碰撞。
画面使用真实深度测试，角色、武器和环境遮挡由同一 3D 空间决定。

角色有 18 个铰接节点。护甲片、肩肘腕、髋膝踝、披风和盾牌分别驱动。
动作是 Godot 中编写的关节姿态混合，并非动作捕捉；刚性护甲原型仍可进一步
打磨手脚接触、惯性与布料。近战使用有方向和时段限制的游戏判定，非刚体剑刃仿真。
剑光使用实际剑刃根部和尖端的运动历史，火星有重力、衰减与地面反弹。
冲击波可见环半径与碰撞半径同步。打击配有短暂停顿、音效、受击闪色和可关闭的震动。

## V4 植被精修

红色树冠已限定在原场景红色点缀区域：树干使用多段渐细枝干和二级枝梢，树冠由
五裂枫叶实例组成，叶脉、折面和边缘色差使用 `maple_*` 1024px 原创材质图；黄色
花朵使用 `petal_*` 叶脉材质、五瓣弧面、花梗和花蕊。绿色林带保持原色与层次。
飘叶采用共享枫叶轮廓网格和预分配 MultiMesh，固定 90 片中等密度；横向阵风、
翻滚和约 9–16 秒循环下落在运行时更新，并将轨迹约束在战斗核心半径 4.5m 之外。

V4 植被检查：`tests/v4_foliage_review.gd` 通过 90 实例、轮廓网格、24 秒轨迹、
移动性和 3 张实机截图检查；战斗 30/30、集成 12/12、角色动画 1,586 帧回归通过。
`tests/v4_combat_visual_review.gd` 的实机预警、弹反、Q 弹道、冲击波和暂停重试通过。

## V5 Boss 与环境精修

角色参考造型已按四视图进一步校正：主角保留棕色碎发、蓝色短装、红围巾/披风、背包、
木盾银边与长剑；Boss 保留弯角头盔、尖刺肩甲、分层板甲和破披风。Boss 黑紫金属材质
已提高中间亮度、金属度并降低粗糙度，边缘与符文在夕阳场景中更清晰。

Boss 普攻固定为正砍、反砍、竖劈三段，第三段带过度发力后的蹲伏恢复；冲刺攻击有约
1 秒弓步蓄力，随后 0.32 秒单手前冲，红眼闪光和拖尾覆盖整个可弹反窗口。大范围砸地
采用双手举剑、剑尖向下、插地蹲伏姿态，并同步扩散冲击波。环境新增雕刻石拱门、苔藓
裂纹巨石、铜制暖光路灯、风化交叉木栅栏和磨损圆形/十字地砖；红枫枝条收回叶冠内部。
动态落叶继续使用 90 片池化 MultiMesh。玩家默认朝鼠标地面方向，攻击方向在起手时锁定；
翻滚按 WASD，静止翻滚回退到鼠标方向。

V5 回归：Boss 检查 35 项、战斗检查 30 项、键鼠集成 23 项、角色动画 1,586 帧、

检查中位帧时间 16.56 ms，P95 32.09 ms，中位绘制调用 506；慢帧主要来自兼容渲染器的
透明植被和材质层。Boss 动作截图位于 `captures/v5_boss_*`，环境截图位于 `captures/v5_env_*`。
